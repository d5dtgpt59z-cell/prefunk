# Security policy

Prefunk is a narrow deterministic preflight, not a comprehensive security audit. Reports contain potential matches that must be independently verified.

Please report suspected vulnerabilities privately to the maintainer before opening a public issue. Never include real credentials, private source, environment files, absolute paths, or an unredacted Prefunk project in a report.

The project accepts security reports for secret leakage, path escape, unreported coverage gaps, unsafe agent instructions, resource exhaustion, signing/update issues, and false-negative or false-positive rule behavior.

Supported releases are the current App Store release and the current default branch. Revoked credentials and repository-history cleanup remain the reporter’s responsibility; Prefunk never performs those actions.
